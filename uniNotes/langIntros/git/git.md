# Basics:

These are the basic git commands which you will use the most, with a basic explanation on how they work

`git init`: it initializes a local repository so you can start working with git

`git add`: it adds a file to the local repository.

`git status`: it shows which files have been modified and what type of modification it succumbed to. It also shows which files have been added and which have been not.

`git commit`: it allows you to commit the added files to the local repository. Use `-m " "` to add a message to your commit.

`git push`: it allows you to push to a remote repository, usually a github one.

`git pull`: it pulls from an existing remote repository, into the current working git local repository, the newest changes that occurred, the local and remote repositories must already be connected.

`git clone`: it's similar to pull, however it takes the remote repository and creates a local one with exactly the same files, folder structure and commit history.
