# Project Objectives:

Build a cinema system to manage screenings and ticket sales. It benefits moviegoers and cinema staff.

# Scope of Work:

Target users are cinemas, their customers, box-office staff and managers.

# Functional Requirements:

- Manage multiple rooms and movies.
- Store each movie's title, duration, genre and director.
- Schedule screenings with a movie, room, date, time and ticket price.
- Let customers buy tickets for a specific screening.
- Prevent overlapping screenings in a room, including cleaning time.
- Give each room numbered seats.
- Let customers view available seats and select them.
- Group tickets for one screening into a booking.
- Temporarily hold selected seats; release them if the hold expires.
- Confirm tickets only after successful payment.
- Prevent two active tickets for the same screening and seat.
- Save the price on each ticket.
- Cancel eligible bookings before the screening starts, release their seats and record refunds.
- Validate tickets at entry so each is used once.
