# Project Objectives:

Build a system that registers patients, doctors and consultations, making care records easier to find. It benefits patients, doctors and administrative staff.

# Scope of Work:

Target users are hospitals, specifically their doctors and administrative staff. Patients benefit but do not use the system directly.

# Functional Requirements:

- Register patients with an ID and name.
- Register doctors with an ID, name and specialty.
- Record each consultation's date, time and diagnosis.
- Link each consultation to one patient and one doctor.
- Allow patients and doctors to have multiple consultations over time.
- Show a patient's consultations.
