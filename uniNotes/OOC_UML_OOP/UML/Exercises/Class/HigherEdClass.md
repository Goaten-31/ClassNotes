# Project Objectives:

Build a system to manage a higher education school's students, teaching and results. It benefits students, teachers and administrators.

# Scope of Work:

Target users are higher education schools, specifically their students, teachers and academic administrators.

# Functional Requirements:

- Enroll each student in one program.
- Organize programs into semesters, teaching units and courses.
- Assign each course to one department.
- Assign every teacher at least one course.
- Let students take several courses.
- Record students' grades and let them view results.

**Added:**

- Create a course offering for each academic year in which a course is taught.
- Assign one or more teachers to each offering.
- Enroll students in offerings, preserving history when courses are retaken.
- Define weighted assessments for each offering, totaling 100%.
- Let assigned teachers record one grade per student per assessment.
- Calculate final course grades from assessment weights.
- Calculate semester averages using course credits.
- Assign teachers and programs to departments.
