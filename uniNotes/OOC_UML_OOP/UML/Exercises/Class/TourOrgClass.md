# Project Objectives:

Simplify tour organization to operations and improve customer service. It benefits clients and agency staff.

# Scope of Work:

Target users are travel agencies, their clients and staff.

# Functional Requirements:

- Record each tour's name, description, duration, destinations and per-person base price.
- Link each destination to one country and optional sightseeing, cultural or outdoor activities.
- Let clients browse tours, view details, check dates, book trips and review booking history.
- Record client details, selected tour, departure and return dates, participant count and total price.
- Calculate totals from participant count and update available places immediately.
- Staff add or modify tours, destinations and activities, and manage bookings.
- Report popular destinations, client preferences and sales.
