# Project Objectives:

Build a system that organizes employees, departments and project assignments. It benefits employees and company management.

# Scope of Work:

Target users are companies, specifically their managers and administrative staff. Employees benefit but do not use the system directly.

# Functional Requirements:

- Record each employee's ID and name.
- Record each department's code and name.
- Assign each employee to one department.
- Allow departments to have multiple employees.
- Record each project's ID and title.
- Let employees work on multiple projects and projects have multiple employees.
- Assign employees to projects and remove them.
