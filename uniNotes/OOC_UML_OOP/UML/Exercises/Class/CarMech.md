# Project Objectives:

Build a system that tracks client vehicles and repairs, helping the shop organize its work. It benefits clients, mechanics and shop staff.

# Scope of Work:

Target users are car repair shops, specifically their mechanics and staff. Clients benefit but do not use the system directly.

# Functional Requirements:

- Register clients with an ID and name.
- Record each vehicle's plate and model.
- Link each vehicle to one owner. Each registered client owns at least one vehicle.
- Record each repair's ID, description, cost and completion status.
- Link each repair to one vehicle and one mechanic.
- Keep multiple repairs for the same vehicle.
- Let mechanics handle multiple repairs.
- Mark repairs as completed.
