# Project Objectives:

Build a system that organizes flights, planes and passenger bookings. It benefits passengers and airline staff.

# Scope of Work:

Target users are airlines, specifically their staff. Passengers benefit but do not use the system directly.

# Functional Requirements:

- Record each plane's registration and seat capacity.
- Record each flight's number, departure time and arrival time.
- Assign one plane to each dated flight.
- Record each passenger's ID and name.
- Link each booking, identified by a reference, to one passenger and one flight.
- Let passengers book multiple flights and flights carry multiple passengers.
- Show available seats and reject bookings for full flights.
- Optionally record seat numbers, with no duplicates on the same flight.
- Cancel bookings and release their places.
