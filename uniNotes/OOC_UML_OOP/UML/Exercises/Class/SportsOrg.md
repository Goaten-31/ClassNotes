# Project Objectives:

Build a system that organizes sports activities, coaches and member attendance. It benefits members, coaches and sports center staff.

# Scope of Work:

Target users are sports centers, specifically their staff. Coaches and members benefit but do not use the system directly.

# Functional Requirements:

- Record each activity's ID, name and capacity.
- Record each coach's and member's ID and name.
- Assign one coach to each activity.
- Let a coach lead multiple activities.
- Let members join multiple activities and activities have multiple members.
- Enroll and withdraw members.
- Reject duplicate enrollments and enrollment in full activities.
